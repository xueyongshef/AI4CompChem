# AI4CompChem

Tutorials and examples for using artificial intelligence in computational chemistry.

## Repository Structure

```text
AI4CompChem/
├── README.md
├── LICENSE
├── requirements.txt
├── tutorials/
│   ├── 01_getting_started/
```

## Getting Started

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
