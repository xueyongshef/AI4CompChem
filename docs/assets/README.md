# Organisation logos

These assets accompany the project's RSC EDI acknowledgement and University of Liverpool logo on the course homepage. They are stored locally so the page does not depend on third-party image requests.

## Royal Society of Chemistry

- File: `royal-society-of-chemistry.svg`
- Artwork: Royal Society of Chemistry logo, reproduced from its 2019 brand guidelines.
- Download source: [Wikimedia Commons file record](https://commons.wikimedia.org/wiki/File:RSC-brand-guidelines-2019_tcm18-246471.svg).
- Original source identified by the file record: [RSC brand guidelines](https://www.rsc.org/images/RSC%20brand%20guidelines%202019_tcm18-246471.pdf).
- The downloaded SVG artwork is unchanged.

## University of Liverpool

- File: `university-of-liverpool.svg`
- Source: the inline header logo on the [University of Liverpool homepage](https://www.liverpool.ac.uk/).
- The original paths, masks, and proportions are preserved. An XML namespace and accessible title make the SVG usable as a standalone image.
- The inherited header fill is made explicit using the university's blue, `#212b58`, from its [Redbrick stylesheet](https://www.liverpool.ac.uk/rb/latest/assets/redbrick.css).

Both logos remain the marks of their respective organisations and are separate from this project's original artwork and source code.
