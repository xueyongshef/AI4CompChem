Sticking point 01

I do not understand an array-shape error.

Starting question “Why does NumPy reject my calculation?”

A more useful question

My coordinate array has shape (3, 3), and I subtract an array of shape (2,). Explain why broadcasting fails by comparing the dimensions. Give me a hint about the intended operation before rewriting the code.

Why this helps: It provides exact shapes and asks for an explanation tied to the operation.

Compare with an example answer

NumPy compares dimensions from the right. Dimensions must be equal or one must be 1. Here the final dimensions are 3 and 2, so they are incompatible. Ask whether you intended to subtract a three-component displacement vector, select two coordinates, or do something else; the correct fix depends on that intention.

Course-authored teaching example. Your AI response may differ.

Follow-up to ask

If I subtract one vector of shape (3,), what will the output shape be?

Check your understanding

Can an array of shape (3,) be subtracted from coordinates of shape (3, 3)?

Reveal the check answer

Yes. It is broadcast across the rows, giving a result of shape (3, 3).

Sticking point 02

I am mixing units and numerical values.

Starting question “Is this energy difference large?”

A more useful question

My toy energies are -75.000 and -74.990 hartree. Help me calculate the difference first, state the sign convention, and explain what I must know before calling it chemically important. Keep any unit conversion explicit.

Why this helps: It separates arithmetic, units, and chemical interpretation.

Compare with an example answer

Taking the second value minus the first gives +0.010 hartree. To interpret it, check whether the energies describe comparable states, geometries, and methods, and whether you need an electronic-energy or free-energy difference. Convert both the number and its unit using a documented factor. These toy values are not calculation results.

Course-authored teaching example. Your AI response may differ.

Follow-up to ask

How would the sign change if I reversed the order of subtraction?

Check your understanding

Does subtracting two energies remove the need to report units?

Reveal the check answer

No. Their difference still has an energy unit.

Sticking point 03

I want help debugging without losing the chance to learn.

Starting question “Write the correct code for me.”

A more useful question

A three-atom coordinate array gives IndexError when I request atom 3. Explain Python indexing and ask me to predict the valid indices. Give one hint before showing a corrected expression.

Why this helps: It requests a limited hint and makes the learner practise the missing concept.

Compare with an example answer

Python uses zero-based indexing. An array with three rows has row indices 0, 1, and 2. Index 3 requests a fourth row. First decide which atom you meant, then choose its corresponding row. Confirm the array shape and atom ordering rather than changing an index at random.

Course-authored teaching example. Your AI response may differ.

Follow-up to ask

How can I select the final row without assuming the number of atoms?

Check your understanding

Which row is selected by index 0?

Reveal the check answer

The first row.
